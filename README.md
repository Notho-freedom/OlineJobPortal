# Online Job Portal

Online job portal and recruitment platform connecting employers with job seekers.

## 🚀 Features

- 📋 **Job listings** - Browse and search job opportunities
- 👤 **User profiles** - Resume and profile management
- 🔍 **Advanced search** - Filter by location, salary, skills
- 📝 **Application tracking** - Track job applications
- 🏢 **Company pages** - Company profiles and reviews

## 🛠️ Tech Stack

- **Frontend**: HTML, JavaScript, CSS
- **Backend**: PHP
- **Database**: MySQL
- **Deployment**: Web hosting
